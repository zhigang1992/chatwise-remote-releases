# ChatWise Remote — releases

Builds of **ChatWise Remote** for macOS: a native client for [ChatWise](https://chatwise.app)
that can also act as the server for your other devices.

- **Server mode** (the Mac that runs ChatWise): starts ChatWise with a local debugging bridge
  and serves your chats on the local network. Shows a QR code / pairing link for other devices.
- **Client mode** (any other Mac) and the iPhone app: pair with that code and chat from there.
  Everything stays on your network; replies come from ChatWise on your Mac.

Download the latest `.zip` from [Releases](../../releases), unzip, and move
**ChatWise Remote.app** to Applications. The app updates itself (Sparkle; feed: `appcast.xml`).

Requires macOS 15 or later. Not affiliated with ChatWise.
